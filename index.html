Layers

Scenario positions are measured from the edges as printed for a 48"×48" table. Changing the table size keeps edge distances and moves the far-side elements with the far edge.

    Legend: red = Attacker (1st player), blue = Defender (2nd player), yellow = shared. Circles = objectives (50/40mm), triangles = flags (Scenario Terrain), squares = caches (30mm). Dashed rings = 3" control range; dotted rings = 5" radius for choosing terrain for a flag.
